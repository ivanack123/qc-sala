# GUIDE FACILE DE QC SALA

Pour la version 1.0.6 de l’appli.

Ce guide est court et simple. Chaque partie a un numéro et un titre. Les étapes indiquent ce qu’il faut faire et, souvent, ce que vous allez entendre.

### Quelques mots utilisés dans ce guide :

- **Lecteur d’écran **: le programme qui parle sur votre téléphone, comme Jieshuo ou TalkBack.
- **Double appui **: appuyer deux fois de suite sur l’écran, rapidement.
- **Balayer **: poser le doigt sur l’écran et le faire glisser vers un côté, comme pour chasser une miette.
- **Explorer **: promener lentement le doigt sur l’écran, sans le lever, pour que votre lecteur d’écran annonce ce qui se trouve dessous.
- **Son de butée **: un son bref qui indique qu’il n’y a plus rien de ce côté, ou que ce que vous avez fait n’a aucun effet.


## 1. AVANT DE COMMENCER : INSTALLER L’APPLI

Si QC Sala n’est pas encore sur votre téléphone, il faut d’abord l’installer. L’appli se présente sous la forme d’un fichier appelé QC-Sala-1.0.6.apk.

L’installation, étape par étape, est expliquée dans un autre guide, le Guide d’installation : c’est le fichier « GUIDE D'INSTALLATION de QC Sala.txt ». Si c’est difficile pour vous, demandez à une personne de confiance de vous aider pour cette partie.

Si vous avez déjà l’appli, passez à la partie 2.


## 2. QU’EST-CE QUE QC SALA ?

QC Sala est une appli pour jouer dans le Salon de QuentinC, sur Internet, avec d’autres personnes. Vous pouvez jouer au Uno, aux dominos, au poker et à bien d’autres jeux.

Elle n’a pas été créée par le propriétaire du Salon. C’est une appli indépendante, pensée pour être facile à utiliser avec un lecteur d’écran.

L’appli n’a pas sa propre voix. Tout vous est dit par votre lecteur d’écran, avec votre voix habituelle.

L’appli vous parle dans la langue de votre téléphone : en français s’il est en français ; en espagnol ou en anglais s’il est dans l’une de ces langues. Si le téléphone est dans une autre langue, elle vous parle en anglais. Par défaut, ce que dit le Salon arrive aussi dans la langue de votre téléphone, si le Salon la propose ; sinon, en anglais. Ce guide utilise les noms en français.


## 3. CE DONT VOUS AVEZ BESOIN

1. Un téléphone sous Android 7 ou version ultérieure. Pour le toucher direct (partie 6), il faut Android 11 ou version ultérieure.
2. Une connexion Internet (Wi-Fi ou données mobiles).
3. Votre nom d’utilisateur et votre mot de passe du Salon (qcsalon.net). Si vous n’avez pas de compte, plus bas sur l’écran de connexion de l’appli se trouve le bouton « Créer un compte », qui ouvre la page du Salon dans votre navigateur. Si c’est difficile, demandez de l’aide pour le créer.


## 4. OUVRIR L’APPLI

1. Cherchez parmi vos applications l’icône appelée « QC Sala ».
2. Ouvrez-la comme n’importe quelle appli. Avec votre lecteur d’écran, c’est un double appui.


## 5. ENTRER DANS LE SALON

### La première fois :

1. Cherchez le champ « Nom d’utilisateur » et saisissez votre nom d’utilisateur.
2. Cherchez le champ « Mot de passe » et saisissez votre mot de passe.
3. Laissez cochée la case « Mémoriser mes identifiants (pour me reconnecter sans les ressaisir) ». Elle est déjà cochée.
4. Appuyez sur le bouton « Se connecter ».
5. Patientez. Si votre téléphone est sous Android 13 ou version ultérieure, une fenêtre intitulée « Notifications du Salon » apparaît. Elle explique à quoi servent les notifications : elles permettent à votre lecteur d’écran de vous lire ce que dit le Salon même quand l’écran est éteint ou qu’une autre appli est au premier plan. Appuyez sur « Continuer ». Si cette fenêtre n’est pas apparue, passez à l’étape 7.
6. Après la fenêtre, le téléphone vous demande si QC Sala peut afficher des notifications. Appuyez sur « Autoriser ».
7. Vous entrez dans le Salon.

### Les fois suivantes :

1. Ouvrez l’appli.
2. Patientez un instant. Si vous avez laissé la case « Mémoriser mes identifiants » cochée, vous entrez directement dans le Salon, sans rien saisir. Vous entendrez « Vérification de votre session enregistrée sur qcsalon.net, patientez un instant. » puis « Session valide. Vous entrez dans le Salon. »

Si vous avez refusé à l’étape 6, à partir du lendemain, quand vous êtes à l’accueil du Salon, une autre fenêtre « Notifications du Salon » peut apparaître, avec deux boutons : « Autoriser les notifications » et « Pas maintenant ». Elle apparaît au plus une fois par jour, et jamais quand vous êtes à une table, pour ne pas vous gêner pendant la partie. Quand vous avez refusé trois fois, en comptant le refus de l’étape 6, elle n’apparaît plus. Si le téléphone ne permet plus à l’appli de vous poser la question, « Autoriser les notifications » ouvre les paramètres des notifications de QC Sala : activez-y le bouton des notifications et revenez avec le bouton Retour. Vous pouvez aussi les autoriser à tout moment depuis « Paramètres de l’appli », section « Lecteur d’écran et gestes », avec le bouton « Autoriser les notifications ».

Les sons de la connexion sont ceux du programme Windows : à l’ouverture de l’appli, vous entendez le son de bienvenue du Salon ; pendant la connexion, un son d’attente ; et, à l’entrée dans le Salon, celui de la connexion établie. Leur volume suit celui des sons du Salon.

La première fois que vous vous connectez en Wi-Fi, l’appli télécharge sur le téléphone les sons du Salon (environ 3,5 Mo, une seule fois), pour qu’ils soient joués instantanément. Avec les données mobiles, elle ne le fait que si vous l’autorisez dans Paramètres, avec la case « Télécharger aussi les sons du Salon avec les données mobiles ».

Si vous entendez que le nom d’utilisateur ou le mot de passe est incorrect, vérifiez votre nom d’utilisateur (il reste dans le champ) et saisissez de nouveau le mot de passe : l’appli l’efface après chaque tentative.

L’appli n’enregistre pas votre mot de passe.


## 6. ACTIVER LE TOUCHER DIRECT

Le toucher direct s’active dans les paramètres d’accessibilité du téléphone, comme une autorisation. Avec lui, vous jouez avec vos doigts sur tout l’écran du Salon. Il ne change rien à votre lecteur d’écran. Il suffit de l’activer une seule fois.

Il n’existe que sur les téléphones sous Android 11 ou version ultérieure. Si le vôtre est plus ancien, sautez cette partie : vous jouez avec votre lecteur d’écran et les grands boutons (partie 9).

Si vous ne voyez pas bien l’écran ou si c’est difficile pour vous, demandez à une personne de confiance de vous aider pour ces étapes.

Les paramètres du téléphone s’affichent dans la langue du téléphone. Voici les termes d’Android 15 en français ; sur d’autres téléphones, surtout les Samsung, ils peuvent être un peu différents.

1. Entrez dans le Salon avec votre lecteur d’écran activé. Au bout d’un moment, une fenêtre intitulée « Toucher direct » apparaît, avec trois étapes.
2. Appuyez sur « Activer le toucher direct ». Les paramètres d’accessibilité du téléphone s’ouvrent.
3. Cherchez « QC Sala : toucher direct ». Il peut se trouver dans la section « Applications téléchargées » ; sur les téléphones Samsung, dans « Applications installées ». Appuyez dessus. Si votre lecteur d’écran annonce « Contrôlé par les paramètres restreints » (le service est grisé), lisez plus bas « Si le service est grisé ». Si le téléphone a ouvert directement la page du service, passez à l’étape 4.
4. Sur sa page, il y a deux boutons. Activez seulement le premier, intitulé « Utiliser QC Sala : toucher direct ». L’autre est un raccourci (sous Android 15, il s’appelle « Raccourci vers QC Sala : toucher direct ») : laissez-le désactivé.
5. Le téléphone demande : « Accorder le contrôle total de votre appareil à QC Sala : toucher direct ? » C’est l’avertissement habituel des services d’accessibilité. Appuyez sur « Autoriser ».
6. Si le téléphone vous propose un « raccourci », n’en cochez aucun. S’il ne vous laisse pas continuer sans en choisir un, choisissez-en un, n’importe lequel, puis, sur cette même page, désactivez le bouton du raccourci.
7. C’est fait : l’appli revient d’elle-même là où vous étiez. Vous n’avez pas à chercher comment revenir. Si, sur votre téléphone, elle ne revient pas, utilisez le bouton Retour jusqu’à revenir dans QC Sala.
8. Vous entendrez « Toucher direct activé. » et comment jouer.

Si vous voulez en savoir plus avant de l’activer, appuyez sur « En savoir plus » dans la fenêtre.

### Si le service est grisé :

À l’étape 3, le service peut être grisé et indiquer « Contrôlé par les paramètres restreints ». Cela arrive souvent quand l’appli ne provient pas d’une boutique d’applications : Android demande une autorisation supplémentaire. Procédez ainsi :

1. Appuyez quand même sur « QC Sala : toucher direct ». Android affiche : « L’appli s’est vu refuser l’accès » (sous Android 13 et 14, le message peut s’intituler « Paramètre restreint »). Appuyez sur « OK ».
2. Utilisez le bouton Retour jusqu’à revenir dans QC Sala. La fenêtre « Le toucher direct est toujours désactivé » apparaît.
3. Appuyez sur « Ouvrir les infos de l’appli ».
4. Ouvrez le menu d’Android « Autres options » (les trois points, en haut à droite) et choisissez « Autoriser les paramètres restreints ». Si le téléphone le demande, saisissez votre code PIN, votre schéma ou votre mot de passe. Cette option n’apparaît qu’après l’avertissement de l’étape 1.
5. Utilisez le bouton Retour jusqu’à revenir dans QC Sala. La fenêtre réapparaît : appuyez sur « Retour aux paramètres d’accessibilité » et reprenez à l’étape 3 de la liste précédente.

Si cette option n’apparaît pas dans le menu, demandez de l’aide à la personne qui vous a installé l’appli. En attendant, jouez avec votre lecteur d’écran et les grands boutons.

Si, dans la fenêtre « Toucher direct », vous avez appuyé sur « Pas maintenant », ce n’est pas grave. La fenêtre réapparaît à une prochaine entrée dans le Salon, une fois l’appli complètement fermée ; au bout de 3 « Pas maintenant », elle n’apparaît plus. Pour l’activer quand vous le voulez : appuyez sur « Plus », puis sur « Paramètres de l’appli », et dans la première section, « Lecteur d’écran et gestes », appuyez sur le bouton « Activer le toucher direct ». La même fenêtre apparaît : appuyez de nouveau sur « Activer le toucher direct ».

Avec le toucher direct activé, tout l’écran du Salon sert à jouer avec vos doigts. Votre lecteur d’écran garde la main sur la barre du bas du téléphone (Retour, Accueil et Applis récentes) et sur deux boutons placés dans les coins du bas, « Plus d’options » et « Chat » (partie 7).


### Si votre banque ne s’ouvre pas

Certaines banques, comme Nu, refusent d’ouvrir leur appli tant que le toucher direct est activé. Elles le prennent pour une appli espionne. Ce n’est pas le cas : QC Sala ne peut ni voir ni toucher ce qu’il y a dans les autres applis, car son service n’a pas l’autorisation de lire les autres fenêtres. Les banques voient seulement qu’un service d’accessibilité est activé.

Que faire : désactivez le toucher direct avant d’ouvrir votre banque, puis réactivez-le quand vous voulez jouer. Vous avez trois moyens :

1. La case. Dans « Paramètres de l’appli », juste sous « Activer le toucher direct », cochez « Désactiver le toucher direct en fermant l’appli ». Elle est décochée par défaut. Une fois cochée, le toucher direct se désactive tout seul quand vous fermez vraiment QC Sala : avec « Quitter le Salon », avec Retour depuis le premier écran de l’appli ou en la retirant des applis récentes. Quand vous revenez dans le Salon, l’appli vous propose de le réactiver. Si vous changez simplement d’appli sans fermer QC Sala, il reste activé.
2. Le bouton des réglages rapides d’Android (le panneau qui s’ouvre en balayant depuis le haut de l’écran). Il s’appelle « QC Sala : toucher direct ». Si le toucher direct est activé, un appui le désactive ; s’il est désactivé, le bouton vous amène à son interrupteur, car Android ne permet pas à une appli d’activer elle-même son service. Pour l’y placer, dans « Paramètres de l’appli », appuyez sur « Ajouter le toucher direct aux réglages rapides » (Android 13 ou plus récent ; sous Android 11 et 12, l’appli explique comment l’ajouter à la main).
3. Les paramètres d’accessibilité d’Android. Désactivez-y « QC Sala : toucher direct », comme vous l’avez activé.

## 7. À QUOI RESSEMBLE L’ÉCRAN DU SALON

### Avec le toucher direct activé :

- Tout l’écran est la zone de jeu.
- Il y a deux boutons dans les coins du bas, juste au-dessus des boutons du téléphone (Retour, Accueil et Applis récentes) :
  - **En bas à gauche **: « Plus d’options ». On y trouve tout ce que proposent les grands boutons : quitter, paramètres, aide et plus encore (partie 9).
  - **En bas à droite **: « Chat ». Il sert à écrire dans le chat (partie 10).
- Pour les trouver, posez le doigt directement dans ce coin, sans le faire glisser depuis le centre de l’écran, et explorez à cet endroit jusqu’à ce que votre lecteur d’écran annonce leur nom. Faites ensuite un double appui au même endroit, dans le coin : ailleurs sur l’écran, un double appui est destiné au jeu et jouerait la carte ou l’option sur laquelle vous êtes.

Sans le toucher direct, vos cartes sont en haut et, plus bas, il y a l’historique, le chat et les grands boutons. Il n’y a pas de coins.

### Le Salon a deux parties pour jouer, appelées zones :

- **Jeu **: vos cartes.
- **Options de jeu **: les options du jeu, comme « Démarrer le jeu » ou « Rappeler les règles activées ». Seulement quand le jeu en propose. À l’écran, elles s’affichent sur plusieurs lignes, pour que les personnes malvoyantes puissent les lire en entier.

Si un jeu utilise des chiffres ou des lettres (par exemple, les dés), le « Clavier du jeu » se trouve à la fin des Options de jeu. Faites un double appui pour l’ouvrir, balayez vers le haut ou vers le bas avec un doigt pour entendre chaque bouton, et faites un double appui sur celui que vous voulez. Le bouton Retour vous en fait sortir.

Les messages du Salon (l’historique) ne sont pas une zone : vous les écoutez avec deux doigts, comme l’explique la partie 8.


## 8. LES GESTES DE BASE

Ces gestes fonctionnent avec le toucher direct activé. Faites-les n’importe où sur l’écran du Salon, sauf sur les deux boutons des coins du bas.

1. Balayage à un doigt vers le haut : vous entendez la carte précédente.
2. Balayage à un doigt vers le bas : vous entendez la carte suivante.
3. Balayage à un doigt vers la droite : vous passez de Jeu à Options de jeu. Si le jeu n’a pas d’options, vous entendez seulement le son de butée. Sur un plateau (comme aux échecs), un balayage à un doigt vers la gauche ou la droite passe d’abord de colonne en colonne ; à la dernière colonne, le son de butée retentit et, si vous continuez, vous passez à Options de jeu.
4. Balayage à un doigt vers la gauche : vous revenez à Jeu.
5. Appui à un doigt : vous réentendez la carte ou l’option sur laquelle vous êtes. C’est utile si vous ne savez plus où vous en êtes.
6. Double appui à un doigt : vous jouez la carte que vous avez entendue, ou vous choisissez l’option que vous avez entendue.
7. Balayage à deux doigts vers le bas : vous piochez une carte, dans les jeux où l’on pioche.
8. Appui à trois doigts : la plupart du temps, vous entendez à qui est le tour. La réponse arrive dès que vous levez les doigts.
9. Maintenir trois doigts immobiles un moment : vous entendez qui est à la table, sans lever les doigts. Cela fonctionne dans tous les jeux, sauf ceux qui se jouent en solo (Solitaire et 2048), où vous entendez l’information la plus utile pour ce jeu.
10. Les messages du Salon sont comme une file : les plus anciens à gauche et les plus récents à droite. Balayage à deux doigts vers la gauche : vous reculez. La première fois, vous entendez le dernier message du Salon ; si vous recommencez, vous entendez les précédents, un par un. Balayage à deux doigts vers la droite : vous avancez, vers les plus récents. Pendant que vous les parcourez, les messages qui arrivent ne vous font pas perdre votre place.
11. Vous pouvez laisser un doigt posé sur l’écran pendant que vous réfléchissez : il ne se passe rien. Si vous balayez ensuite, le balayage compte.
12. Maintenir deux doigts immobiles un moment puis les lever (une légère vibration vous indique quand les lever) : la fenêtre « Gestes du jeu » s’ouvre, avec tout ce que vous pouvez faire dans ce jeu et ce que fait chaque geste.
13. Deux traits à la suite avec un doigt, sans le lever : vers le bas puis vers la gauche, c’est Retour, comme le bouton Retour du téléphone. Vers le bas puis vers la droite, deux fois de suite, ouvre le menu de votre lecteur d’écran. La première fois, vous entendez « Écran rendu à votre lecteur : refaites le geste » ; la deuxième fois, votre lecteur l’exécute.
14. Deux autres gestes à un doigt, aussi en deux traits à la suite sans le lever : vers le haut puis vers le bas, vous allez au premier élément de la zone (la première carte ou la première option) ; vers le bas puis vers le haut, au dernier. Ils fonctionnent aussi dans l’historique, pour aller au premier ou au dernier message. Faites chaque trait long, comme un balayage normal. Si vous étiez déjà sur cet élément, vous entendez une butée.

La première fois que vous entrez dans chaque jeu, vous entendez : « Maintenez deux doigts sur l’écran pour découvrir les gestes de ce jeu. » C’est le geste 12.

Quand vous jouez ou piochez, vous entendez tout ce que dit le Salon en une seule annonce. La carte qui se trouve ensuite devant vous n’est pas annoncée : vous l’entendez en parcourant vos cartes ou avec un appui à un doigt. Si vous voulez l’entendre, dans « Paramètres de l’appli », section « Écran et mouvement », cochez « Annoncer la carte qui se trouve devant vous après avoir joué ou pioché ».

### Au même endroit, il y a deux autres cases, décochées par défaut :

- **« Annoncer la carte que vous piochez » **: quand vous piochez, vous entendez aussi quelle carte vous avez reçue, à la fin de l’annonce du Salon, par exemple « 7 rouge ». Elle sert dans les jeux où l’on pioche, comme le Uno, et dans les jeux de dominos.
- « Quand vous piochez, annoncer que vous avez pioché plutôt que de répéter le compte » : elle sert surtout au Ninety nine. Par défaut, quand vous piochez dans ce jeu, vous entendez le compte, comme dans le programme Windows. Avec la case cochée, vous entendez l’annonce du Salon qui dit que vous avez tiré une carte.

Si vous utilisez Jieshuo : Jieshuo coupe une annonce quand une autre arrive. C’est pourquoi, si une nouvelle annonce arrive alors que la précédente n’était pas terminée, l’appli vous dit d’abord ce qui manquait, puis la nouvelle. Il arrive que vous entendiez une deuxième fois la fin d’une phrase ; c’est voulu, pour que vous ne manquiez aucun coup. Si c’est vous qui faites un geste, la nouvelle annonce coupe la précédente, comme sur l’ordinateur. Si l’appli répète trop, demandez de l’aide : dans « Paramètres de l’appli », section « Avancé », on peut modifier « Débit de votre voix dans Jieshuo ».

Les échecs, Puissance 4, le go et Reversi ne se jouent que contre des personnes depuis l’appli : avec des bots, la partie ne démarre pas. Si vous en ajoutez un, vous entendez l’avertissement du Salon, puis : « Dans cette appli, ce jeu se joue uniquement contre des personnes : retirez les bots et invitez quelqu’un à la table. » Dans les autres jeux, vous pouvez jouer avec des bots.

### Au Uno :

- Pour annoncer « Uno », secouez le téléphone. Vous pouvez aussi balayer vers le haut avec deux doigts.
- Pour accuser de bluff celui qui a joué le +4, balayez vers le haut avec trois doigts. Cela ne fonctionne que si la table utilise la règle du bluff.
- Si le téléphone compte une secousse sans que vous le vouliez, dans « Paramètres de l’appli », section « Écran et mouvement », appuyez sur « Sensibilité aux secousses » et choisissez « Ferme » : ainsi, seule une forte secousse compte. Si le téléphone a du mal à détecter vos secousses, choisissez « Douce ».

### Au Monopoly :

- Pour payer et sortir de prison, balayez vers le haut avec trois doigts.
- Pour enchérir lors d’une vente aux enchères, balayez vers le bas avec trois doigts.

L’appli reconnaît toute seule le jeu de la table où vous êtes. Vous n’avez rien à choisir. Si un jour vous entendez « Rien tant que je n’ai pas identifié le jeu », patientez un instant et réessayez. Si rien ne change, demandez de l’aide : dans « Paramètres de l’appli », section « Avancé », le jeu se choisit avec le bouton « Choisir le jeu manuellement ».

Quand un geste ne sert à rien dans ce jeu, vous entendez le son de butée et « Rien dans ce jeu ». Ce n’est pas grave.

Si vous demandez quelque chose, par exemple à qui est le tour, et que le Salon ne répond pas, le son de butée retentit aussi au bout d’un moment. La première fois à chaque table, vous entendez pourquoi, avec une phrase qui commence par « Le Salon n’a pas répondu ».

Certains coups risqués, comme jeter définitivement une carte, vous demandent d’abord confirmation. Vous entendez par exemple : « Se coucher ? Pour confirmer, refaites le geste ; sinon, ne faites rien. » Pour confirmer, refaites le même geste dans les 5 secondes. Si vous faites autre chose, c’est annulé et vous entendez « Annulé. »

Pour savoir quel geste fait quoi dans le jeu où vous êtes : ouvrez « Plus d’options », passez au groupe « Table et Salon » et choisissez « Aide rapide du jeu » (partie 9). Elle vous indique chaque action avec son geste, par exemple : « Appui à deux doigts : connaître le décompte en cours. » Pour revenir au jeu, appuyez sur « Retour au jeu », tout en bas, ou utilisez le bouton Retour.


## 9. LES GRANDS BOUTONS

Sans le toucher direct, les grands boutons sont en bas. Ils font la même chose que les gestes :

- **« Jouer ou valider » **: joue la carte sur laquelle vous êtes.
- **« Piocher » **: pioche une carte. Dans d’autres jeux, son nom change et indique ce qu’il fait. Il n’apparaît que lorsque l’appli sait dans quel jeu vous êtes.
- **« Menu contextuel » **: demande au jeu le menu de la carte ou de l’option sur laquelle vous êtes, dans les jeux qui en ont un.
- **« Gestes du jeu » **: ouvre une liste de tout ce que vous pouvez faire dans ce jeu. Par exemple, « À qui est le tour ».
- **« Retour » **: revient en arrière dans le menu du jeu.
- **« Plus » **: propose d’autres choses, comme « Paramètres de l’appli », « Aide sur les gestes » et « Quitter le Salon ».

Avec une très grande taille de texte sur le téléphone, ou avec peu de place à l’écran (par exemple, avec le téléphone à l’horizontale, en mode paysage), seuls « Jouer ou valider », « Retour » et « Plus » restent en bas. Les autres boutons passent dans « Plus ».

Sans le toucher direct, jouez comme d’habitude avec votre lecteur d’écran : parcourez vos cartes et appuyez deux fois sur celle que vous voulez jouer. Et servez-vous de ces boutons.

Avec le toucher direct, tout cela se trouve dans « Plus d’options », le bouton du coin inférieur gauche :

1. Posez le doigt directement dans le coin inférieur gauche, juste au-dessus des boutons du téléphone, sans le faire glisser depuis le centre, jusqu’à entendre « Plus d’options ». Faites un double appui au même endroit, dans le coin.
2. « Plus d’options » occupe tout l’écran et s’ouvre toujours sur sa première option. À une table, vous entendez : « Plus d’options. Partie. Quitter la table ». Hors d’une table : « Plus d’options. Partie. État de la connexion », suivi de l’état de la connexion.
3. Balayez vers le bas avec un doigt pour entendre l’option suivante, et vers le haut pour la précédente.
4. Les options sont réparties en quatre groupes : Partie ; Table et Salon ; Historique ; et Aide, paramètres et sortie. Balayez vers la droite avec un doigt pour passer au groupe suivant, et vers la gauche pour revenir au précédent.
5. Quand vous entendez celle que vous voulez, faites un double appui.
6. Pour sortir de « Plus d’options », utilisez le bouton Retour du téléphone. Vous revenez là où vous étiez.

Les gestes pour jouer, comme piocher avec un balayage à deux doigts vers le bas, fonctionnent aussi dans « Plus d’options ».

Deux options de « Plus d’options » à connaître :

- « Flux audio » (seulement à une table, dans le groupe « Table et Salon ») : elle permet à toute la table d’entendre une radio ou un fichier audio. Si vous êtes le chef de table, le Salon vous demande le lien ; les autres l’activent ou la coupent avec la même option.
- « Volumes » (dans le groupe « Aide, paramètres et sortie ») : elle ouvre une fenêtre avec trois barres : son, notifications, et musique et flux. Montez-les ou baissez-les avec le geste de votre lecteur d’écran prévu pour cela, et le bouton « Fermer » vous ramène au jeu.

Si vous le souhaitez, vous pouvez mettre l’une ou l’autre sur un geste, dans « Personnaliser les gestes » (même groupe « Aide, paramètres et sortie »). Il y a aussi là des actions pour passer au volume suivant, le monter et le baisser.


## 10. ÉCRIRE DANS LE CHAT

### Avec le toucher direct :

1. Posez le doigt directement dans le coin inférieur droit, juste au-dessus des boutons du téléphone, sans le faire glisser depuis le centre, jusqu’à entendre « Chat ». Faites un double appui au même endroit, dans le coin.
2. Le clavier s’ouvre. Écrivez votre message.
3. Appuyez sur la touche d’envoi du clavier, ou sur le bouton « Envoyer ».
4. Pour revenir au jeu, utilisez le bouton Retour du téléphone. Vous revenez là où vous étiez.

### Sans le toucher direct :

1. Cherchez le champ de chat, en bas, et faites un double appui.
2. Le clavier s’ouvre. Écrivez votre message.
3. Appuyez sur la touche d’envoi du clavier, ou sur le bouton « Envoyer ».

Le nom du champ vous indique qui va lire votre message : à une table, « Message à votre table » ; à l’accueil du Salon, « Message à tout le Salon (tout le monde le lit) ».

Pour renvoyer un message que vous avez déjà écrit : dans « Plus d’options » (ou dans « Plus »), groupe « Table et Salon », choisissez « Réutiliser un message envoyé », puis le message.


## 11. QUITTER LA TABLE ET LE SALON

### Pour quitter la table (et revenir à l’accueil du Salon) :

1. Avec le toucher direct, ouvrez « Plus d’options », le bouton du coin inférieur gauche. Sans le toucher direct, appuyez sur le bouton « Plus ».
2. À une table, la première option est « Quitter la table ». Faites un double appui.
3. On vous demande une seule fois de confirmer :
   - Si la partie n’a pas encore commencé, c’est presque toujours l’appli qui pose la question, dans une fenêtre : « Voulez-vous vraiment quitter la table ? » Le bouton par défaut est « Non ». Appuyez sur « Oui ». Vous entendez « Vous quittez la table. »
   - Si la partie a déjà commencé, c’est le Salon qui pose la question : vous entendez « Vous quittez la table. » puis, aussitôt, sa question : « Êtes-vous sûr de vouloir quitter la table ? » Son « Oui » et son « Non » apparaissent dans la zone Jeu, à la place de vos cartes : allez jusqu’à « Oui » et faites un double appui.
4. Pendant que le Salon répond, le double appui ne joue aucune carte, au cas où vous appuieriez une fois de trop.

### Pour quitter le Salon, avec le toucher direct :

1. Ouvrez « Plus d’options » et balayez vers la droite avec un doigt jusqu’à entendre le dernier groupe, « Aide, paramètres et sortie ».
2. La première option de ce groupe est « Quitter le Salon ». Faites un double appui.

### Pour quitter le Salon, sans le toucher direct :

1. Appuyez sur le bouton « Plus ».
2. Cherchez « Quitter le Salon ». C’est la dernière option de la fenêtre. Appuyez dessus.

Dans les deux cas, l’appli vous demande : « Voulez-vous vraiment quitter le Salon ? L’appli se fermera ; votre session est conservée. » Le bouton par défaut est « Non ». Appuyez sur « Oui ». L’appli se ferme et vous revenez là où vous étiez sur votre téléphone. La prochaine fois que vous ouvrirez QC Sala, vous entrerez directement, sans retaper votre nom d’utilisateur ni votre mot de passe.

Dans « Plus d’options », à la fin du groupe « Aide, paramètres et sortie », loin de « Quitter le Salon », se trouve « Fermer la session qcsalon.net ». Ne l’utilisez que si vous voulez que le téléphone oublie votre compte. Celle-ci vous ramène bien à l’écran de connexion.


## 12. EN CAS DE PROBLÈME

- Si vous entendez qu’il n’y a pas d’Internet : vérifiez que le Wi-Fi ou les données mobiles sont activés et réessayez.
- **Si le jeu s’est coupé **: patientez un peu. La plupart du temps, l’appli se reconnecte toute seule. Vous pouvez aussi relancer la connexion vous-même avec l’option « Relancer la connexion », qui n’apparaît que lorsque la connexion est coupée : dans « Plus », c’est la première option ; dans « Plus d’options », elle vient juste après l’état de la connexion.
- Si l’appli vous redemande votre nom d’utilisateur et votre mot de passe : saisissez-les de nouveau.
- Si vous n’entendez pas le Salon quand l’écran est éteint ou qu’une autre appli est au premier plan : autorisez les notifications (partie 5).
- Si le Salon se coupe quand vous éteignez l’écran : Android peut mettre l’appli en veille pour économiser la batterie. Dans « Paramètres de l’appli », appuyez sur le bouton « Laisser QC Sala connectée écran éteint ». Android demande « Autoriser l’appli à toujours s’exécuter en arrière-plan ? » : appuyez sur « Autoriser ».
- **Si les gestes ne font rien **: dans « Paramètres de l’appli », section « Lecteur d’écran et gestes », vérifiez que le toucher direct est activé et que la case « Gestes du Salon » est cochée. Si rien ne change, désactivez le toucher direct avec le bouton « Désactiver le toucher direct » et jouez avec votre lecteur d’écran et les grands boutons.
- Si vous ne trouvez pas les boutons « Plus d’options » et « Chat » : posez le doigt directement dans un coin du bas de l’écran, juste au-dessus des boutons du téléphone, sans le faire glisser depuis le centre.
- **Si vous voulez en savoir plus **: appuyez sur « Plus » (ou ouvrez « Plus d’options » et passez au groupe « Aide, paramètres et sortie »), puis sur « Aide sur les gestes ». Vous entendez d’abord l’essentiel ; pour tout savoir, appuyez sur « Aide complète ».


## 13. METTRE L’APPLI À JOUR

Depuis la version 1.0.2, QC Sala vous prévient d’elle-même quand une nouvelle version existe : elle la cherche à l’ouverture, puis toutes les trois heures tant qu’elle est ouverte et connectée. Une fenêtre s’ouvre avec deux boutons : appuyez sur « Mettre à jour », patientez, et quand Android demande « Voulez-vous mettre à jour cette appli ? », appuyez de nouveau sur « Mettre à jour ». La première fois, l’appli vous demande une autorisation et vous conduit au bon paramètre : activez l’interrupteur de QC Sala et revenez. Si vous ne voulez pas mettre à jour tout de suite, appuyez sur « Plus tard » : l’appli vous reproposera cette version la prochaine fois que vous l’ouvrirez.

Si la nouvelle version sort pendant que vous jouez, par défaut l’appli vous le dit une fois à voix haute, et la fenêtre apparaît quand vous quittez la table. Si vous préférez l’avoir tout de suite, changez-le dans « Paramètres de l’appli », sous « Mises à jour », avec « Me prévenir en pleine partie ». Attention : si vous mettez à jour en pleine partie, Android ferme l’appli et vous quittez la partie.

Après une mise à jour, la première fois que vous ouvrez l’appli, une fenêtre présente les nouveautés de la version. Appuyez sur « Retour au jeu » (ou « Fermer » si vous n’êtes pas dans le Salon). Pour les revoir, sous « Mises à jour », appuyez sur « Nouveautés de cette version ».

Si vous voulez vérifier vous-même, dans « Paramètres de l’appli », sous « Mises à jour », appuyez sur « Rechercher les mises à jour maintenant ».

- À un proche ou un ami de confiance qui voit l’écran.
