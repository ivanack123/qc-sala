# GUIDE D’INSTALLATION DE QC SALA

Version de l’appli : 1.0.5. Guide rédigé en octobre 2026.

QC Sala est une appli non officielle pour jouer au Salon de QuentinC (qcsalon.net) avec votre lecteur d’écran. Elle n’est pas disponible sur Google Play : elle s’installe à partir d’un fichier. Ce guide vous accompagne pas à pas, du moment où vous recevez le fichier jusqu’à votre arrivée dans le Salon, et vous dit ce que vous entendrez sur chaque écran.

### Comment lire ce guide :

- Chaque partie a un numéro et un titre en majuscules. Vous pouvez passer de l’une à l’autre avec la fonction de recherche de votre lecteur d’écran.
- Chaque étape correspond à une seule action.
- Quand le guide dit « appuyez sur », avec votre lecteur d’écran cela veut dire : placez-vous sur cet élément et appuyez deux fois.
- Ce qui est entre guillemets, c’est ce qu’affiche l’écran.
- Android affiche ses écrans dans la langue de votre téléphone. Les noms d’Android sont donnés ici en français de France. Sur d’autres marques, comme Samsung ou Motorola, ils peuvent légèrement varier.

En toute transparence : ce guide est nouveau et n’a pas encore été testé de bout en bout sur un vrai téléphone. Il a été testé sur des téléphones virtuels sous Android 10, 13, 14, 15 et 16, tels que Google les fournit, en ouvrant le fichier depuis l’appli Fichiers. En français, seuls les écrans d’Android 15 ont été vérifiés ; Samsung, WhatsApp et Chrome ne l’ont pas encore été. Si quelque chose ne correspond pas à ce que vous entendez, prévenez la personne qui vous a envoyé l’appli, pour que le guide soit corrigé.


## 1. CE DONT VOUS AVEZ BESOIN

1. Un téléphone sous Android 7 ou version ultérieure. L’appli fonctionne sur les téléphones 32 bits comme sur les 64 bits.
2. Pour le toucher direct, Android 11 ou version ultérieure. Le toucher direct permet de jouer en balayant avec un doigt tout l’écran du Salon (partie 8). Sous Android 7 à 10, vous pouvez aussi jouer : le Salon s’utilise avec la navigation habituelle de votre lecteur d’écran, les gestes à deux et trois doigts et les boutons.
3. Le fichier de l’appli : QC-Sala-1.0.5.apk. Il pèse environ 1,7 Mo. Les fichiers dont le nom se termine par .apk sont des applis Android.
4. Le code PIN, le schéma ou le mot de passe qui déverrouille votre téléphone, si vous en avez un. Android vous le demande à certaines étapes.
5. Votre nom d’utilisateur et votre mot de passe qcsalon.net. Si vous n’avez pas de compte, l’appli propose un bouton pour en créer un (partie 6).
6. Une connexion Internet, en Wi-Fi ou en données mobiles.
7. Une dizaine de minutes.
8. Si possible, quelqu’un qui voit l’écran et peut vous accompagner, au cas où une étape se compliquerait. Ce n’est pas obligatoire.

Si vous ne savez pas quelle version d’Android équipe votre téléphone, cherchez-la dans les paramètres du téléphone, dans « À propos du téléphone ».

N’installez que le fichier reçu de la personne qui vous a transmis l’appli, et non un fichier trouvé ailleurs.


## 2. UNIQUEMENT SUR SAMSUNG : DÉSACTIVER LE BLOQUEUR AUTOMATIQUE

Si votre téléphone n’est pas un Samsung, passez cette partie.

Sur de nombreux Samsung récents, le « Bloqueur automatique » est activé par défaut. Tant qu’il est activé, le téléphone n’accepte que les applis du Google Play Store et du Galaxy Store : il ne vous laissera donc pas installer QC Sala. C’est pourquoi il faut le désactiver avant d’ouvrir le fichier.

1. Ouvrez les Paramètres du téléphone.
2. Appuyez sur « Sécurité et confidentialité ».
3. Appuyez sur « Bloqueur automatique ».
4. Désactivez son bouton. Si le téléphone vous demande de confirmer ou de saisir votre code PIN, faites-le.
5. Revenez avec le bouton Retour.

Si vous ne trouvez pas « Bloqueur automatique », c’est sans doute que votre téléphone ne l’a pas : passez à la partie 3.

Une fois l’installation terminée, vous pouvez le réactiver si vous le souhaitez. Pour installer une nouvelle version de QC Sala à la main, il faudra le désactiver de nouveau.


## 3. OUVRIR LE FICHIER

Il y a deux chemins : le chemin A, si vous avez reçu le fichier par WhatsApp, et le chemin B, si vous avez reçu un lien.

### Chemin A, par WhatsApp :

1. Ouvrez la discussion dans laquelle vous avez reçu le fichier.
2. Cherchez le message qui contient le fichier « QC-Sala-1.0.5.apk ».
3. Appuyez dessus. S’il doit d’abord être téléchargé, attendez la fin du téléchargement et appuyez de nouveau dessus.
4. Android affiche un avertissement au sujet de l’installation d’applis inconnues. Passez à la partie 4.

Si WhatsApp n’ouvre pas le fichier, demandez un lien de téléchargement à la personne qui vous l’a envoyé et suivez le chemin B.

### Chemin B, avec un lien :

1. Appuyez sur le lien. Votre navigateur télécharge le fichier « QC-Sala-1.0.5.apk ».
2. Si le navigateur vous demande si vous voulez vraiment le télécharger, confirmez. Ne le faites que si le lien vous a été envoyé par une personne de confiance.
3. Une fois le téléchargement terminé, ouvrez l’appli de gestion des fichiers du téléphone. Sur Samsung, elle s’appelle « Mes fichiers » ; sur d’autres téléphones, « Fichiers », « Files » ou un nom proche.
4. Ouvrez le dossier « Téléchargements ». Sur certains téléphones, ce dossier s’ouvre tout seul.
5. Appuyez sur le fichier « QC-Sala-1.0.5.apk ».
6. Android affiche un avertissement au sujet de l’installation d’applis inconnues. Passez à la partie 4.


## 4. AUTORISER CETTE APPLI À INSTALLER

La première fois, Android refuse d’installer les applis qui ne viennent pas d’une boutique d’applications. Il vous demande une autorisation pour l’appli depuis laquelle vous avez ouvert le fichier : WhatsApp, votre navigateur ou l’appli de gestion des fichiers. Si vous avez déjà donné cette autorisation, Android saute cette partie et vous emmène directement à la partie 5. Si votre téléphone est sous Android 7, allez plus bas, à « Sous Android 7, c’est différent ».

Sur certains téléphones, par exemple sous Android 10 ou 13, quand vous ouvrez le fichier depuis « Fichiers », cet avertissement ne s’affiche pas. À la place, un avertissement sans titre explique que votre téléphone et vos données personnelles sont plus vulnérables aux attaques d’applis inconnues. Il a deux boutons : l’un pour annuler, l’autre pour continuer. Appuyez sur celui qui permet de continuer et passez à la partie 5.

1. Vous entendrez un avertissement. Son titre est en général le nom de cette appli, mais ce peut être un nom étrange, comme « Gestionnaire de téléchargement » ou un nom technique comme « com.android.providers.media » ; c’est normal, n’en tenez pas compte. Vous le reconnaissez à son texte : « Pour votre sécurité, l’installation d’applis inconnues provenant de cette source n’est pas autorisée sur ce téléphone actuellement. Vous pouvez modifier cette option dans les paramètres. » Il propose les boutons « Annuler » et « Paramètres ».
2. Appuyez sur « Paramètres ».
3. L’écran « Installation d’applis inconnues » s’ouvre. Vous entendrez un texte qui explique que votre téléphone et vos données personnelles sont plus vulnérables aux attaques d’applis inconnues. C’est l’avertissement habituel d’Android.
4. Activez le bouton « Autoriser depuis cette source ». Sur certains téléphones, son nom peut être un peu différent.
5. Android revient tout seul à l’installation. S’il ne revient pas, appuyez sur Retour.

Sous Android 7, c’est différent : il n’y a qu’une seule autorisation pour tout le téléphone, et elle s’appelle « Sources inconnues ».

1. Ouvrez les paramètres du téléphone.
2. Appuyez sur « Sécurité ».
3. Activez « Sources inconnues ». Si le téléphone vous demande de confirmer, confirmez.
4. Revenez avec le bouton Retour.
5. Ouvrez de nouveau le fichier (partie 3) et passez à la partie 5.

Une fois l’installation terminée, vous pouvez désactiver « Sources inconnues ».

Sous Android 8 ou version ultérieure, si vous voulez plus tard retirer l’autorisation à l’appli depuis laquelle vous avez installé QC Sala, elle se trouve dans les paramètres du téléphone : « Applications », « Accès spéciaux des applis », « Installation d’applis inconnues ». Sur Samsung, elle se trouve dans « Sécurité et confidentialité », parmi les autres paramètres de sécurité. Si vous la retirez, Android vous la redemandera quand vous installerez une nouvelle version.


## 5. INSTALLER L’APPLI ET PASSER L’AVERTISSEMENT PLAY PROTECT

1. Vous entendrez « QC Sala » et « Voulez-vous installer cette appli ? », avec les boutons « Annuler » et « Installer ».
2. Appuyez sur « Installer ».
3. Un avertissement « Google Play Protect », la protection de Google, va probablement s’afficher. Vous entendrez « Analyse d’appli recommandée » et « Cette appli est inconnue de Play Protect. Afin de protéger votre appareil et vos données, envoyez-la à Google pour une analyse de sécurité. » En dessous se trouvent « Plus de détails » et les boutons « Analyser l’appli » et « Ne pas installer l’appli ». Cet avertissement apparaît parce que Play Protect ne connaît pas l’appli, qui ne vient pas d’une boutique. S’il n’apparaît pas, passez directement à l’étape 8.
4. Appuyez sur « Plus de détails ». N’appuyez pas sur « Ne pas installer l’appli ».
5. L’avertissement s’agrandit et dit aussi : « L’analyse peut prendre un certain temps. Les résultats s’afficheront sur cet écran. Fonctionnement de Play Protect ». À la fin de ce texte se trouve « Installer sans analyser ».
6. Appuyez sur « Installer sans analyser ». Attention : ce n’est pas un bouton à part, mais un lien à l’intérieur de ce même texte. Si rien ne se passe quand vous appuyez deux fois, ou si autre chose s’ouvre, revenez avec le bouton Retour et cherchez les liens dans le menu de votre lecteur d’écran. Vous pouvez aussi demander à quelqu’un d’appuyer sur ces mots.
7. Si votre téléphone a un verrouillage de l’écran, vous entendrez « Installer l’appli sans l’analyser ? » et « Play Protect n’a pas validé cette appli ». Saisissez votre code PIN, votre schéma ou votre mot de passe. S’il n’a pas de verrouillage, l’appli s’installe sans rien demander.
8. Patientez. Cela peut prendre jusqu’à une minute. Pendant l’installation, l’écran n’affiche qu’un bouton, pour annuler : n’appuyez pas dessus. À la fin, vous entendrez « Application installée. », avec les boutons « OK » et « Ouvrir ».
9. Appuyez sur « Ouvrir » et passez à la partie 6.

À l’étape 4, au lieu de « Plus de détails », vous pouvez aussi appuyer sur « Analyser l’appli » : le téléphone envoie l’appli à Google pour qu’elle soit vérifiée, et le résultat s’affiche sur ce même écran. Ce chemin n’a pas encore été testé.

Si vous avez appuyé sur « Ne pas installer l’appli », vous entendrez « Application non installée. », avec le bouton « OK ». Appuyez sur « OK » et ouvrez de nouveau le fichier (partie 3). L’autorisation de la partie 4 reste acquise.

**Si Play Protect bloque l’appli.** Sur certains téléphones, au lieu de l’avertissement décrit plus haut, Play Protect pourrait afficher « Appli bloquée pour protéger votre appareil » et empêcher l’installation. Cela peut arriver parce que QC Sala contient un service d’accessibilité, le toucher direct. Dans ce cas :

1. Fermez l’avertissement.
2. Prévenez la personne qui vous a envoyé le fichier, pour chercher une solution ensemble.
3. Si vous décidez de l’installer quand même, vous pouvez suspendre Play Protect uniquement le temps de l’installation. Ouvrez le Play Store.
4. Appuyez sur l’icône de votre profil, en haut à droite.
5. Appuyez sur « Play Protect ».
6. Appuyez sur le bouton « Paramètres » (une roue dentée, en haut à droite).
7. Désactivez « Analyser les applications avec Play Protect ». Si le téléphone vous demande de confirmer, confirmez.
8. Ouvrez de nouveau le fichier (partie 3) et installez QC Sala.
9. Dès que l’installation est terminée, revenez sur ce même écran du Play Store et réactivez « Analyser les applications avec Play Protect ».


## 6. OUVRIR QC SALA ET VOUS CONNECTER À VOTRE COMPTE

1. Si vous n’avez pas appuyé sur « Ouvrir », cherchez l’icône « QC Sala » parmi vos applis et ouvrez-la.
2. Vous entendrez « QC Sala » et « Appli non officielle pour le Salon de QuentinC ». C’est l’écran de connexion.
3. Cherchez le champ « Nom d’utilisateur » et saisissez votre nom d’utilisateur qcsalon.net.
4. Cherchez le champ « Mot de passe » et saisissez votre mot de passe.
5. Laissez cochée la case « Mémoriser mes identifiants (pour me reconnecter sans les ressaisir) ». Elle est déjà cochée.
6. Appuyez sur le bouton « Se connecter ». Vous entendrez « Connexion… Patientez un instant. »
7. Patientez. Sous Android 13 ou version ultérieure, la première fois, la fenêtre « Notifications du Salon » s’affiche d’abord : passez à la partie 7. Sous Android 12 ou version antérieure, vous entrez directement dans le Salon.

Les fois suivantes, si « Mémoriser mes identifiants » est cochée, vous entendrez à l’ouverture de l’appli « Vérification de votre session enregistrée sur qcsalon.net, patientez un instant. » et vous entrerez sans rien saisir.

Si vous n’avez pas de compte : sous le bouton « Se connecter », sous le titre « Plus d’options », se trouve le bouton « Créer un compte (s’ouvre dans votre navigateur) ». Au même endroit se trouve « Mot de passe perdu ? (s’ouvre dans votre navigateur) ».

Si vous entendez « Connexion impossible : le nom d’utilisateur ou le mot de passe est incorrect, ou qcsalon.net a refusé la connexion », vérifiez votre nom d’utilisateur, qui reste saisi, et saisissez de nouveau le mot de passe.

L’appli n’enregistre pas votre mot de passe.


## 7. LES NOTIFICATIONS

Les notifications permettent à votre lecteur d’écran de vous lire ce que dit le Salon quand l’écran est éteint ou qu’une autre appli est au premier plan, par exemple pendant que vous répondez à un message. Sans elles, vous ne l’entendez pas : cela reste seulement dans l’historique.

### Sous Android 13 ou version ultérieure, la première fois que vous vous connectez :

1. Une fenêtre intitulée « Notifications du Salon » s’affiche. Vous entendrez « Quand vous appuierez sur “Continuer”, Android vous demandera si QC Sala peut afficher des notifications », puis à quoi elles servent.
2. Appuyez sur « Continuer ».
3. Android vous demande : « Autoriser QC Sala à vous envoyer des notifications ? » Appuyez sur « Autoriser ».
4. Vous entrez dans le Salon.

Sous Android 12 ou version antérieure, cette question n’apparaît pas.

Si vous avez refusé, vous pourrez corriger cela plus tard. Tant que l’autorisation manque, le Salon vous propose de nouveau la fenêtre « Notifications du Salon », avec les boutons « Autoriser les notifications » et « Pas maintenant ». Elle ne s’affiche qu’à l’accueil du Salon, jamais à une table, une fois par jour au maximum, et elle cesse de s’afficher une fois que vous avez refusé trois fois, en comptant le « Ne pas autoriser » d’Android à la première connexion. Vous trouverez aussi le bouton « Autoriser les notifications » dans les Paramètres de QC Sala, section « Lecteur d’écran et gestes ». Si Android ne permet plus à l’appli de vous poser la question, ce bouton ouvre les paramètres des notifications de QC Sala : activez-y le bouton des notifications, puis revenez avec le bouton Retour.

Une fois les notifications autorisées, tant que vous êtes connecté au Salon, vous trouverez dans vos notifications la notification persistante « Connecté au Salon ». Son bouton « Déconnecter » vous fait quitter le Salon ; il faut appuyer dessus deux fois, pour éviter de partir par erreur.


## 8. ACTIVER LE TOUCHER DIRECT

Le toucher direct est un petit service d’accessibilité de QC Sala. Il ne lit pas l’écran et ne parle pas : il permet seulement à l’écran du Salon de recevoir vos appuis pendant que celui-ci est ouvert. Avec lui, vous jouez avec un doigt : vers le haut ou le bas, vous parcourez les cartes et les options ; vers la gauche ou la droite, vous changez de zone ; et d’un double appui, vous jouez, sans rien modifier dans votre lecteur d’écran. La barre de navigation d’Android et les autres applis restent gérées par votre lecteur d’écran. Il suffit de l’activer une fois.

Si votre téléphone est sous Android 10 ou version antérieure, passez cette partie ainsi que les parties 9 et 10 : le toucher direct n’y est pas disponible. Dans les Paramètres de QC Sala, vous entendrez « Toucher direct : nécessite Android 11 ou version ultérieure », et vous jouerez avec votre lecteur d’écran et les boutons.

1. Entrez dans le Salon avec votre lecteur d’écran activé. Au bout d’un moment, une fenêtre intitulée « Toucher direct » s’affiche. Vous entendrez « Pour jouer en balayant l’écran avec un doigt, activez le toucher direct. Cela se fait une seule fois, en trois étapes », puis les étapes. Elle propose les boutons « Activer le toucher direct », « En savoir plus » et « Pas maintenant ».
2. Appuyez sur « Activer le toucher direct ». Les paramètres d’accessibilité d’Android s’ouvrent. Parfois, c’est directement la page du service qui s’ouvre : dans ce cas, passez à l’étape 6.
3. Cherchez « QC Sala : toucher direct » dans la liste. Il peut se trouver dans la section « Applications téléchargées » ; sur les Samsung, dans « Applications installées ».
4. Écoutez ce que votre lecteur d’écran annonce avec le nom. Si vous entendez « Contrôlé par les paramètres restreints », ou si le service est grisé, allez tout de suite à la partie 9. Sinon, passez à l’étape 5. Entendre « Désactivé » est normal : cela veut seulement dire qu’il n’est pas encore activé.
5. Appuyez sur « QC Sala : toucher direct ». Sa page s’ouvre. Sous Android 13 et 14, au lieu de sa page, un avertissement de paramètre restreint s’affiche, même si le service n’était pas grisé : dans ce cas, allez à la partie 9, étape 3.
6. Activez le premier bouton, « Utiliser QC Sala : toucher direct ». Plus bas se trouve un autre bouton, celui du raccourci : laissez-le désactivé. Si le bouton est grisé, ou si au lieu de la question de l’étape 7 vous entendez « L’appli s’est vu refuser l’accès » ou « Paramètre restreint », allez à la partie 9, étape 3.
7. Android vous demande : « Accorder le contrôle total de votre appareil à QC Sala : toucher direct ? », avec les boutons « Autoriser », « Refuser » et « Désinstaller ». C’est l’avertissement habituel des services d’accessibilité : celui-ci ne lit pas l’écran, ne parle pas et n’enregistre rien. Appuyez sur « Autoriser ». N’appuyez pas sur « Désinstaller ».
8. Si Android vous propose un raccourci (le bouton Accessibilité ou les touches de volume), n’en cochez aucun : ce n’est pas nécessaire et cela entrerait en conflit avec les raccourcis de votre lecteur d’écran. S’il ne vous laisse pas continuer sans en choisir un, choisissez n’importe lequel puis, sur cette même page, désactivez le bouton du raccourci.
9. QC Sala revient d’elle-même. Vous entendrez : « Toucher direct activé. Dans le Salon, vous n’explorez plus au toucher : balayez vers le haut ou vers le bas avec un doigt pour parcourir, et appuyez deux fois pour choisir. “Plus d’options” se trouve en bas à gauche, et “Chat”, en bas à droite. » Si QC Sala ne revient pas d’elle-même, appuyez sur Retour jusqu’à la retrouver.

Si votre téléphone est réglé dans une autre langue que celle de QC Sala, la fenêtre de l’étape 1 vous prévient : « Attention : Android affiche ses paramètres dans la langue de votre téléphone, et non dans celle de QC Sala ; ces noms y apparaissent donc dans cette langue. » Si le service porte un autre nom dans cette langue, la fenêtre vous indique aussi sous quel nom il apparaît.

Si vous avez appuyé sur « Pas maintenant », la fenêtre réapparaît les fois suivantes où vous ouvrez QC Sala et entrez dans le Salon, jusqu’à 3 fois en tout. Et vous la retrouvez quand vous voulez dans les Paramètres de QC Sala. Pour y aller depuis le Salon, appuyez sur le bouton « Plus » (ou « Plus d’options », si le toucher direct est déjà activé), puis sur « Paramètres de l’appli ». Sur l’écran de connexion, le bouton « Paramètres » se trouve tout en bas. Dans les Paramètres, la première section, « Lecteur d’écran et gestes », contient le bouton « Activer le toucher direct ».

Pour le désactiver, utilisez le bouton « Désactiver le toucher direct » des Paramètres de QC Sala et répondez « Oui ». Ne le désactivez pas avec un raccourci pendant que le Salon est ouvert : votre lecteur d’écran peut perdre presque tout l’écran, même dans d’autres applis. Si cela vous arrive, utilisez de nouveau le même raccourci, ou redémarrez votre lecteur d’écran avec son raccourci.


Étape finale recommandée : la laisser connectée écran éteint. Android, surtout sur Samsung, peut mettre l’appli en veille écran éteint pour économiser la batterie et couper votre connexion au Salon. Pour l’éviter, ouvrez les Paramètres de QC Sala et, dans la première section, « Lecteur d’écran et gestes », sous l’élément des notifications, appuyez sur le bouton « Laisser QC Sala connectée écran éteint ». Android demande « Autoriser l’appli à toujours s’exécuter en arrière-plan ? » : appuyez sur « Autoriser ». Ensuite, les Paramètres indiquent « Écran éteint, QC Sala reste connectée au Salon. »


## 9. S’IL EST GRISÉ OU SI UN AVERTISSEMENT S’AFFICHE : AUTORISER LES PARAMÈTRES RESTREINTS

Cela arrive souvent sous Android 13 ou version ultérieure quand l’appli ne vient pas d’une boutique. Android demande une autorisation supplémentaire, qui ne s’accorde qu’une seule fois. Respectez cet ordre : l’option de l’étape 7 n’existe pas tant qu’Android ne vous a pas montré l’avertissement de l’étape 2.

1. Dans les paramètres d’accessibilité, appuyez sur « QC Sala : toucher direct » (ou sur son bouton, si vous êtes déjà sur sa page), même s’il est grisé ou si votre lecteur d’écran l’annonce comme désactivé.
2. Android affiche l’avertissement « L’appli s’est vu refuser l’accès ». Vous entendrez « L’accès à cette autorisation peut exposer vos informations financières et personnelles à un risque. » et « Si elle ne dispose pas d’un accès à cette autorisation restreinte, l’appli peut ne pas fonctionner correctement. » Sous Android 13 et 14, l’avertissement s’intitule « Paramètre restreint » et dit « Pour votre sécurité, ce paramètre est actuellement indisponible. »
3. Appuyez sur « OK ». Sous Android 16, ce bouton peut porter un autre nom : c’est le seul bouton de l’avertissement. Inutile d’ouvrir le lien « Découvrez comment autoriser l’accès » : ce guide vous explique comment faire.
4. Appuyez sur Retour jusqu’à revenir dans QC Sala. La fenêtre « Le toucher direct est toujours désactivé » s’affiche. Vous entendrez « Le toucher direct ne semble pas s’être activé », puis ces mêmes étapes, expliquées. Elle propose les boutons « Ouvrir les infos de l’appli », « Retour aux paramètres d’accessibilité » et « Fermer ».
5. Appuyez sur « Ouvrir les infos de l’appli ». L’écran « Infos sur l’appli » d’Android s’ouvre, celui de QC Sala. On y trouve des boutons comme « Désinstaller » et « Forcer l’arrêt » : n’appuyez pas dessus.
6. Cherchez le bouton « Autres options » de cet écran (les trois points, en haut à droite) et appuyez dessus. S’il n’y est pas, ouvrez ce même écran depuis les paramètres du téléphone, comme l’explique la partie 10, étape 3 : par ce chemin, le bouton apparaît bien. Ensuite, rouvrez QC Sala depuis vos applis.
7. Dans le menu, appuyez sur « Autoriser les paramètres restreints ». Sur certains téléphones, le libellé peut être un peu différent.
8. Si votre téléphone a un verrouillage de l’écran, vous entendrez « Confirmez votre identité » et « Utilisez le verrouillage de l’écran pour continuer ». Saisissez votre code PIN, votre schéma ou votre mot de passe. Vous entendrez peut-être « Paramètres restreints autorisés pour QC Sala ». Si vous n’avez pas de verrouillage, l’autorisation est accordée immédiatement.
9. Appuyez sur Retour pour revenir dans QC Sala. La fenêtre « Le toucher direct est toujours désactivé » s’affiche de nouveau.
10. Appuyez sur « Retour aux paramètres d’accessibilité ».
11. Cherchez de nouveau « QC Sala : toucher direct ». Il n’est plus grisé. Sous Android 15, vous entendrez « Désactivé » avec le nom.
12. Reprenez la partie 8 à partir de l’étape 5 : appuyez dessus, activez « Utiliser QC Sala : toucher direct » et appuyez sur « Autoriser ».

Quand vous mettez QC Sala à jour, il est très rare de devoir refaire tout cela, mais cela peut arriver (voir la partie 11). Si vous la désinstallez puis la réinstallez, il faut le refaire.


## 10. SI L’OPTION N’APPARAÎT PAS

Si « Autoriser les paramètres restreints » ne figure pas dans le menu des trois points, ou si vous ne trouvez pas le bouton des trois points :

1. Vérifiez l’ordre. L’option n’apparaît qu’après l’avertissement « L’appli s’est vu refuser l’accès » (ou « Paramètre restreint »). Avant cet avertissement, sous Android 15, le bouton des trois points n’existe même pas. Revenez à la partie 9 et recommencez à l’étape 1 : appuyez sur le service grisé jusqu’à ce que l’avertissement s’affiche.
2. Si la fenêtre « Le toucher direct est toujours désactivé » ne s’affiche pas quand vous revenez dans QC Sala (elle ne s’affiche pas si plus de 10 minutes se sont écoulées depuis que vous avez ouvert les paramètres), allez dans les Paramètres de QC Sala et appuyez sur « Activer le toucher direct ». Dans la fenêtre qui s’affiche, appuyez de nouveau sur « Activer le toucher direct ». Quand les paramètres d’Android s’ouvrent, revenez avec le bouton Retour : à votre retour dans QC Sala, la fenêtre « Le toucher direct est toujours désactivé » s’affiche.
3. Vous pouvez aussi accéder aux infos de l’appli sans passer par QC Sala : dans les paramètres du téléphone, ouvrez « Applications », cherchez « QC Sala » et ouvrez-la. Sur certains téléphones, il faut d’abord appuyer sur « Voir toutes les applis ». Utilisez aussi ce chemin si vous avez ouvert les infos de l’appli depuis QC Sala sans trouver les trois points : lors d’un essai sous Android 13, c’est arrivé, et ce chemin les a fait apparaître.
4. Si votre téléphone est sous Android 12 ou version antérieure, cette autorisation n’existe pas. Si le service ne s’active pas, le problème vient d’ailleurs : prévenez la personne qui vous a envoyé l’appli.
5. Si l’option n’apparaît toujours pas malgré tout cela, prévenez la personne qui vous a envoyé l’appli.

En attendant, QC Sala fonctionne sans le toucher direct : le Salon s’utilise normalement avec la navigation habituelle de votre lecteur d’écran et avec les boutons.


## 11. PASSER À UNE NOUVELLE VERSION

Une nouvelle version de QC Sala s’installe toujours par-dessus celle que vous avez. Ne désinstallez pas l’ancienne : la désinstallation efface vos paramètres, et il faudrait réactiver le toucher direct et redonner les autorisations.

Depuis la version 1.0.2, l’appli vous prévient d’elle-même quand une nouvelle version existe et se met à jour avec son propre bouton. Elle demande à GitHub, le site où elle est publiée, s’il y en a une : à l’ouverture, puis toutes les trois heures tant qu’elle reste ouverte et connectée au Salon ; cette demande ne contient que le nom de l’appli et son numéro de version. La méthode à la main, avec le fichier, fonctionne toujours, et c’est celle qu’il vous faut si votre version est antérieure à la 1.0.3.

### Avec le bouton de l’appli (depuis la version 1.0.2) :

1. Quand une nouvelle version existe, une fenêtre intitulée « Une nouvelle version de QC Sala est disponible » apparaît. Vous entendrez le numéro de la nouvelle version et celui de la vôtre, le poids du téléchargement et les nouveautés. Appuyez sur « Mettre à jour ». Avec « Plus tard », la fenêtre se ferme et l’appli vous reproposera cette version la prochaine fois que vous l’ouvrirez.
2. La première fois, Android demande que vous autorisiez QC Sala à installer des applis. Une fenêtre intitulée « Il manque une autorisation » apparaît. Appuyez sur « Ouvrir les paramètres », activez l’interrupteur de QC Sala et revenez dans l’appli : le téléchargement démarre tout seul.
3. Patientez. L’appli dit « Téléchargement de la nouvelle version » et vous prévient à 25 %, 50 % et 75 %. Puis elle vérifie que le fichier est bien QC Sala.
4. L’installateur d’Android s’ouvre. Vous entendrez « Voulez-vous mettre à jour cette appli ? », avec les boutons « Annuler » et « Mettre à jour ». Appuyez sur « Mettre à jour » (sous Android 10, sur le bouton pour installer).
5. Si Play Protect s’affiche, faites comme dans la partie 5 : « Plus de détails », « Installer sans analyser » et votre code PIN s’il est demandé.
6. Une fois terminé, Android ferme QC Sala. Rouvrez-la depuis son icône : une fenêtre présente les nouveautés de cette version. Appuyez sur « Retour au jeu » (ou « Fermer » si vous n’êtes pas dans le Salon). Pour la revoir, dans les Paramètres de QC Sala, section « Mises à jour », appuyez sur « Nouveautés de cette version ».

Si, sur un Samsung, l’installation n’avance pas, désactivez le Bloqueur automatique (partie 2) et réessayez. Si vous voulez vérifier vous-même, sans attendre l’avis, ouvrez les Paramètres de QC Sala et, dans la section « Mises à jour », appuyez sur « Rechercher les mises à jour maintenant ».

Si la nouvelle version sort pendant que vous êtes à une table, par défaut l’appli vous le dit une fois à voix haute, et la fenêtre apparaît quand vous quittez la table. Si vous préférez l’avoir tout de suite, changez-le dans les Paramètres de QC Sala, section « Mises à jour », avec « Me prévenir en pleine partie » ; attention : si vous mettez à jour en pleine partie, Android ferme l’appli et vous quittez la partie.

### À la main, avec le fichier :

1. Si vous avez un Samsung et que vous avez réactivé le Bloqueur automatique, désactivez-le (partie 2).
2. Ouvrez le nouveau fichier comme la première fois (partie 3).
3. Vous entendrez « Voulez-vous mettre à jour cette appli ? », avec les boutons « Annuler » et « Mettre à jour ». Sous Android 10, le message est différent : il vous demande si vous voulez installer une mise à jour de cette appli et précise que vos données ne seront pas perdues ; appuyez alors sur le bouton pour installer. Avant cela, l’avertissement de la partie 4 peut réapparaître : faites comme la première fois.
4. Appuyez sur « Mettre à jour ».
5. Si Play Protect s’affiche, faites comme dans la partie 5 : « Plus de détails », « Installer sans analyser » et votre code PIN s’il est demandé.
6. Une fois la mise à jour terminée, ouvrez QC Sala.

En général, tout est conservé : vos paramètres, votre session enregistrée, le toucher direct activé et l’autorisation des paramètres restreints. Avec le bouton de l’appli, tout est toujours conservé, y compris sous Android 14. Seulement si vous mettez à jour à la main, avec le fichier, sous Android 14, le toucher direct peut être désactivé : Android le désactive pour toute appli mise à jour depuis un fichier ; ce n’est pas un problème de QC Sala. Quand vous entrez dans le Salon, QC Sala vous prévient si c’est arrivé. Pour le vérifier vous-même, ouvrez les Paramètres de QC Sala et écoutez la ligne du toucher direct. S’il est désactivé, appuyez sur « Activer le toucher direct » et refaites les parties 8 et 9.

Si, pendant la mise à jour, le téléphone indique que l’appli n’a pas été installée, ne désinstallez rien : prévenez la personne qui vous a envoyé le fichier.


## 12. EN CAS DE PROBLÈME

Rien ne se passe quand vous appuyez sur le fichier, ou WhatsApp ne l’ouvre pas. Demandez un lien de téléchargement et suivez le chemin B de la partie 3.

Vous avez un Samsung et il refuse l’installation, alors que vous avez donné l’autorisation de la partie 4. Désactivez le Bloqueur automatique (partie 2) et ouvrez de nouveau le fichier.

Vous avez entendu « Application non installée. » Cela arrive par exemple si vous avez appuyé sur « Ne pas installer l’appli ». Appuyez sur « OK » et ouvrez de nouveau le fichier. Si cela se reproduit sans que vous ayez appuyé sur « Ne pas installer l’appli », prévenez la personne qui vous a envoyé le fichier.

Play Protect affiche « Appli bloquée pour protéger votre appareil ». Reportez-vous à la fin de la partie 5.

**Vous ne trouvez pas l’icône de QC Sala.** Cherchez-la avec la recherche d’applis de votre téléphone. Si elle n’apparaît pas, l’installation ne s’est sans doute pas terminée : ouvrez de nouveau le fichier.

Vous entendez « Pas de connexion Internet, ou qcsalon.net est introuvable. » Vérifiez le Wi-Fi ou les données mobiles, puis réessayez.

Vous ne trouvez pas « QC Sala : toucher direct » dans les paramètres d’accessibilité. Cherchez-le dans « Applications téléchargées » ou, sur Samsung, dans « Applications installées ». Si votre téléphone est réglé dans une autre langue, le service peut porter un autre nom : la fenêtre « Toucher direct » de QC Sala vous indique lequel. Sous Android 10 ou version antérieure, il n’apparaît pas, car le toucher direct nécessite Android 11 ou version ultérieure.

Le toucher direct est activé, mais dans le Salon vos gestes à un doigt ne font rien. Dans les Paramètres de QC Sala, vérifiez que la case « Gestes du Salon » est cochée. Elle est cochée par défaut.

Vous avez désactivé le toucher direct avec un raccourci et votre lecteur d’écran ne lit presque plus l’écran. Utilisez de nouveau le même raccourci, ou redémarrez votre lecteur d’écran avec son raccourci. Ensuite, désactivez le toucher direct depuis les Paramètres de QC Sala.

Après une mise à jour à la main, le toucher direct est désactivé. Cela peut arriver. Refaites les parties 8 et 9. Avec le bouton de l’appli, cela n’arrive pas.

**L’appli annonce une nouvelle version, mais elle ne s’installe pas.** Lisez ce que dit l’appli : elle vous explique si la connexion a échoué, si le fichier est endommagé, s’il ne s’agit pas de QC Sala ou s’il manque de la place, et dans tous ces cas elle n’installe rien. Vérifiez votre connexion et relancez la recherche dans les Paramètres, « Mises à jour », « Rechercher les mises à jour maintenant ». Si rien n’y fait, installez le nouveau fichier à la main (parties 3 à 5).

Vous n’entendez pas le Salon quand l’écran est éteint ou qu’une autre appli est au premier plan. Il manque les notifications : reportez-vous à la partie 7.

La personne qui vous a envoyé l’appli vous demande un journal pour trouver un problème. Dans les Paramètres de QC Sala, presque tout en bas, sous le titre « Journal de débogage », cochez la case « Enregistrer le journal de débogage », refaites ce qui n’a pas fonctionné et suivez les indications de cette personne. Ne décochez pas la case avant qu’elle vous le dise : quand vous la décochez, ou quand vous fermez la session, le fichier est effacé. Attention : tant qu’il est activé, il enregistre aussi le chat du Salon et les messages des autres joueurs ; votre mot de passe, en revanche, n’est pas enregistré. Activez-le uniquement quand on vous le demande.


## 13. DÉSINSTALLER

1. Dans QC Sala, ouvrez les Paramètres : dans le Salon, appuyez sur « Plus » ou « Plus d’options », puis sur « Paramètres de l’appli » ; sur l’écran de connexion, appuyez sur le bouton « Paramètres », tout en bas.
2. Si le toucher direct est activé, appuyez sur « Désactiver le toucher direct ». Vous entendrez « Désactiver le toucher direct ? Pour le réactiver, vous devrez repasser par les paramètres d’accessibilité d’Android. » Appuyez sur « Oui ».
3. Quittez QC Sala avec le bouton Accueil du téléphone.
4. Ouvrez les paramètres du téléphone et allez dans « Applications ».
5. Cherchez « QC Sala » et ouvrez-la. Sur certains téléphones, il faut d’abord appuyer sur « Voir toutes les applis ».
6. Appuyez sur « Désinstaller ». N’appuyez pas sur « Archiver » : cette option retire l’appli mais conserve ses données.
7. Confirmez que vous voulez la désinstaller.

Vos paramètres et votre session enregistrée sont effacés du téléphone. Votre compte qcsalon.net, lui, n’est pas supprimé.

Si vous voulez remettre le téléphone dans son état d’origine, retirez l’autorisation d’installer des applis inconnues à l’appli depuis laquelle vous avez installé QC Sala (fin de la partie 4) et, sur Samsung, réactivez le Bloqueur automatique (partie 2).

Pour apprendre à jouer avec QC Sala, lisez le « GUIDE FACILE de QC Sala ».
